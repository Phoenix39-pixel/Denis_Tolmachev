# 🐍 Змейка • Neon Edition

Собственная реализация классической «Змейки» на Python + Tkinter
с неоновой тёмной темой и дополнительными механиками:
золотая/ядовитая еда, телепорты, рост скорости, система рекордов.

## 🎯 Правила игры

- Управление: **WASD** или **стрелки**.
- Собирайте 🍎 красные яблоки — +1 очко, змейка растёт.
- 🟡 Золотая еда — +5 очков, растёт быстрее.
- 🟣 Фиолетовая (ядовитая) — −2 очка и ускорение.
- 🔵 Голубая пара клеток — портал: входишь в одну — выходишь из другой.
- Каждые 5 яблок скорость увеличивается.
- Проигрыш: столкновение со стеной или с собой.
- **Space** — пауза, **R** — рестарт, **Esc** — выход.
- Рекорд сохраняется в `highscore.txt`.

## 🛠 Технологии

- Python 3.9+
- Tkinter (стандартная библиотека, установка не требуется)
- Только стандартная библиотека, внешних зависимостей нет

## 🧱 Структура проекта

| Файл | Назначение |
|------|-----------|
| `main.py` | точка входа, окно Tkinter, отрисовка, игровой цикл |
| `game.py` | класс `Game` — вся игровая логика (не зависит от UI) |
| `snake.py` | класс `Snake` — движение, коллизии, сегменты |
| `food.py` | класс `Food` — генерация еды и порталов |
| `settings.py` | константы (размер поля, цвета, скорости) |
| `img/` | графические материалы |
| `README.md` | документация |

## 🧠 Основные классы

- **`Snake`** — хранит `body: list[tuple]`, обрабатывает `move()`,
  `check_wall_collision()`, `check_self_collision()`.
- **`Food`** — генерирует яблоки/золото/яд/порталы, метод `try_eat(head)`.
- **`Game`** — связывает змейку и еду, считает очки и скорость,
  управляет состоянием (`game_over`, `paused`), хранит рекорд.
- **`SnakeApp`** — слой представления: Canvas, HUD, обработка клавиш.

Разделение логики и графики позволяет легко перейти на Pygame или
мобильную платформу.
